# Yijian Liu — Personal Homepage

A focused, static personal site for Yijian Liu. It presents research in lattice cryptography alongside a more personal cultural layer: music, Manchester City, snooker, and animation.

## Run locally

Open `index.html` directly in a browser, or serve this directory with any static-file server. Selecting an album updates the compact Spotify player; every album also keeps a direct Spotify link as a fallback.

## Update content

- Academic copy and publications: `index.html`
- Visual design and responsive behavior: `styles.css`
- Navigation, portal entrance, album playback, reveals, and email copying: `script.js`
